# SnipBar

**A native macOS menu bar snippet manager and 50-entry direct-paste clipboard stack.**

SnipBar is built strictly with native Apple frameworks—**AppKit (`NSPanel` + `NSStatusItem`)**, **SwiftUI**, **SwiftData**, **LocalAuthentication (Touch ID)**, and **Carbon HotKeys**—with zero Electron overhead, zero external package dependencies, and zero telemetry.

It is pre-configured with **"Sign to Run Locally"** (`CODE_SIGN_IDENTITY = "-"`) so anyone can build, run indefinitely without 7-day provisioning expiry, and share `SnipBar.app` at **$0 cost** with no Apple Developer account required.

## Key Features

### Dual-Engine Workflow (`Snippets` ↔ `Clipboard`)
- **Curated Snippets (`⌘⇧Space` or `⌥S`)**: Summon a non-activating floating popover directly over full-screen Spaces. Fuzzy-search by title, content, or inline `#tag` tokens, filter by pinned items or tags, preview full contents inline, or create new snippets on the fly with `⌘N`.
- **50-Entry Clipboard Stack (`⌘⇧V`)**: Automatically records up to 50 deduplicated plain-text copies (configurable `10–50`) in the background. Hold `⌘` while tapping `⌘⇧V` (or arrows) to cycle through history, then **release `⌘` to auto-paste immediately**—no Enter key needed.
- **Instant Deep Search down to `#50`**: Inside the `⌘⇧V` bezel, press `⌘F` or `/` to search all 50 cached clippings by text, source app name, or stack slot (e.g., `#50`). Press `S` (or `⌘S` in search mode) to promote any clipping into a permanent tagged Snippet.
- **Seamless Mode Switching**: Press `Tab` inside the menu bar popover to flip between **Snippets** and **Clipboard** without lifting your hands from the keyboard.

### Dynamic Snippet Variables
Non-secret snippets expand template placeholders automatically when copied:
- `{{date}}` — Current localized abbreviated date
- `{{time}}` — Current localized short time
- `{{clipboard}}` — Current plain-text clipboard contents (automatically skips concealed secrets)

### Privacy, Secrets & Local-Only Storage
- **Masked Secrets**: Marking a snippet as sensitive masks list previews (`••••••••`), excludes its body from fuzzy search, uses `SecureField` in the editor, and supports optional **Touch ID / Apple Watch / macOS login password** confirmation via `LAContext`.
- **Hardened Pasteboard Handling**: Secret copies block Universal Clipboard / Handoff (`.currentHostOnly`), attach `org.nspasteboard.ConcealedType`, `TransientType`, and `AutoGeneratedType` markers (respected by 1Password, Raycast, Paste, Maccy, Alfred, and SnipBar's own history monitor), and auto-clear after a configurable delay (`5–300s`, default `30s`) only if `NSPasteboard.general.changeCount` has not changed.
- **Owner-Only Storage**: All data stays 100% local under `~/Library/Application Support/SnipBar/` (`chmod 0700` directory; `clipboard-history.json` locked to `chmod 0600`).

### Library Manager & Portable Team Sharing (`.snipbar.json`)
- **3-Column Library (`⌘L` or `⌘,`)**: Manage snippets, tags, masked secrets, clipboard history, hotkeys, auto-paste behavior, and Launch at Login (`SMAppService.mainApp`) in a dedicated native `NavigationSplitView` window.
- **Selective Export & Import**: Export all or filtered subsets of snippets as human-readable `.snipbar.json` files with tag color preservation, exact-duplicate detection on import, and masked secrets **unchecked by default** (with an explicit plaintext warning if selected).

## Keyboard Shortcuts

### Global Hotkeys (Zero-Permission Carbon)
| Shortcut | Action |
| :--- | :--- |
| `⌘⇧Space` *(or `⌥S`)* | Toggle SnipBar menu bar popover (configurable in Library) |
| `⌘⇧V` | Summon Clipboard Stack bezel; tap repeatedly to cycle, release `⌘` to auto-paste |

### Menu Bar Popover
| Shortcut | Action |
| :--- | :--- |
| `Tab` | Switch between **Snippets** and **Clipboard** tabs |
| `↑` / `↓` | Move selection up / down |
| `↵` | Copy selected snippet (or Auto-Paste if enabled) / Direct-paste selected clipboard entry |
| `⌥↵` | Toggle Auto-Paste for this copy action |
| `⌘1` – `⌘9` | Instantly copy / paste visible items `#1` through `#9` |
| `⌘N` | Open inline **New Snippet** composer (`⌘↵` to save, `Esc` to cancel) |
| `⌘L` or `⌘,` | Open **SnipBar Library** window |
| `Esc` | Close preview → clear search query → close popover |

### Clipboard Stack Bezel (`⌘⇧V`)
| Shortcut | Action |
| :--- | :--- |
| `⌘⇧V` / `V` / `←` `→` `↑` `↓` | Cycle through cached clipboard entries |
| **Release `⌘`** | Auto-paste the highlighted clipping into the previous app |
| `↵` or `1` – `9` | Paste highlighted clipping or jump-paste slots `1–9` |
| `⌘F` or `/` | Enter **Search Mode** (filter by text, source app, or `#rank`) |
| `S` *(or `⌘S` in Search)* | Promote active clipping into a permanent Snippet |
| `Delete` / `⌫` | Remove active clipping from clipboard history |
| `Esc` | Clear search / cancel inline save / dismiss bezel |

## Getting Started

### Requirements
- **macOS 14.0 (Sonoma)** or newer
- **Xcode 16+** / **Swift 5.10+**
- **[XcodeGen](https://github.com/yonaskolb/XcodeGen)** (only needed to generate `SnipBar.xcodeproj` and build the `.app` bundle)

### Download a Prebuilt Release

Download the latest `SnipBar-macOS-v*.zip` (and optional `.sha256` checksum) from [GitHub Releases](https://github.com/rawat-divyanshu/SnipBar-macOS/releases), unzip it, and move `SnipBar.app` to `/Applications`:

```bash
# Optional: verify checksum before opening
shasum -a 256 -c SnipBar-macOS-v1.0.0.zip.sha256
```

### Build & Run in Xcode (From Source)

```bash
git clone https://github.com/rawat-divyanshu/SnipBar-macOS.git
cd SnipBar-macOS

brew install xcodegen
xcodegen generate
open SnipBar.xcodeproj
```

1. Press **⌘R** in Xcode (ad-hoc **"Sign to Run Locally"** is pre-configured—no Apple ID, Team, or Bundle ID changes needed).
2. Look for the diagonal interlocking **SnipBar** icon in the top-right macOS menu bar, or press **⌘⇧Space** / **⌘⇧V**.
3. **Right-click** the menu bar icon for quick access to **Clipboard History (`⌘⇧V`)…**, **Open SnipBar Library…**, **About SnipBar**, and **Quit SnipBar**.

### Run Unit Tests & CLI Build (SwiftPM)

```bash
swift test --parallel
swift build -c release
```

### Package a Release `SnipBar.app` Bundle

Run the bundled release script to clean artifacts, execute the full test suite, generate a fresh Xcode project, compile a Release build signed with `CODE_SIGN_IDENTITY="-"`, and package `dist/SnipBar-macOS.zip`:

```bash
./scripts/build-release.sh
```

> **First Launch Note (Ad-Hoc Signed Builds):** When moving an unnotarized local build of `SnipBar.app` to `/Applications` on another Mac, macOS Gatekeeper may ask for confirmation once. Open **System Settings → Privacy & Security → Open Anyway**, or run `xattr -cr /Applications/SnipBar.app` once.
>
> **Accessibility Permission:** SnipBar never requests Input Monitoring. macOS Accessibility access is requested **only on demand** when you trigger or enable Auto-Paste.

## macOS Engineering & Privacy Caveats Handled

| Area | macOS Pitfall / Caveat | How SnipBar Solves It |
| :--- | :--- | :--- |
| **Window Focus & Full-Screen Spaces** | SwiftUI `MenuBarExtra(.window)` steals app activation before capturing `frontmostApplication`, breaks full-screen Spaces, and drops search focus. | Custom `FloatingPopoverPanel: NSPanel` (`.nonactivatingPanel` + `.fullScreenAuxiliary` + `.popUpMenu`) records `previousFrontmostApp` *before* summoning. |
| **Release-`⌘` Auto-Paste Without Keylogger Prompts** | `NSEvent.modifierFlags` goes stale inside a `.nonactivatingPanel` `.accessory` app, while global key monitors trigger Input Monitoring prompts. | `ClipboardBezelController` combines local/global `flagsChanged` monitors with a 20ms `CGEventSource.flagsState(.combinedSessionState)` live HID watchdog—requiring zero Input Monitoring permission. |
| **Sign to Run Locally + Touch ID** | Keychain entitlements (`kSecUseDataProtectionKeychain`) force hardware-locked provisioning profiles that expire after 7 days. | Uses ad-hoc signing (`-`) + `LAContext.evaluatePolicy(.deviceOwnerAuthentication)` (`BiometricAuthService`) for Touch ID / Apple Watch / macOS login password confirmation with zero provisioning profiles. |
| **Masked Secrets & Hardened Storage** | Sensitive snippets shouldn't leak over screen-shares, search probing, or shared-machine file access. | `isSecret` masks rows (`••••••••`), excludes bodies from `FuzzySearchEngine`, gates reveal/copy behind Touch ID, and restricts `~/Library/Application Support/SnipBar` to `0700` (`clipboard-history.json` to `0600`). |
| **Clipboard History & Handoff Leaks** | Copying secrets broadcasts to iCloud Handoff and leaks into 3rd-party clipboard managers (and SnipBar's own monitor). | `ClipboardService` calls `prepareForNewContents(with: .currentHostOnly)` and writes `ConcealedType` / `TransientType` / `AutoGeneratedType`. `ClipboardHistoryStore` explicitly skips concealed, transient, auto-generated, and 1Password pasteboard items. |
| **Safe Clipboard Auto-Clear** | Naive timers wipe whatever the user copied *after* a secret snippet. | Captures `NSPasteboard.general.changeCount` on write and only clears the clipboard if `changeCount` is still unchanged when the timer fires. |
| **Zero-Permission Global Hotkeys** | `NSEvent.addGlobalMonitorForEvents(matching: .keyDown)` prompts for Input Monitoring. | Uses `Carbon.HIToolbox` `RegisterEventHotKey` for both the Snippets popover and `⌘⇧V` Clipboard Stack with zero permissions. |
| **Auto-Paste Modifier Corruption** | Releasing `⌘` from `⌘⇧V` or pressing `⌥↵` can leave physical modifier keys held, mutating synthesized `⌘V` into `⌘⇧V` or `⌘⌥V`. | Polls `targetApp.isActive` (up to 200ms), waits briefly for conflicting physical modifiers to clear (up to 90ms), and posts `kVK_ANSI_V` using an isolated `CGEventSource(stateID: .privateState)` with clean `.maskCommand`. |
| **`LSUIElement` Broken Text Shortcuts** | Hiding the Dock icon (`LSUIElement = YES`) removes the Edit menu, breaking `⌘C`, `⌘V`, `⌘X`, `⌘A`, and `⌘Z` in panels and detached windows. | Installs a standard AppKit Edit menu (`installStandardEditMenu()`) at launch so responder-chain editing works reliably everywhere. |
