# Changelog

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-23

### Added
- **Native macOS Menu Bar Popover (`FloatingPopoverPanel`)**: Non-activating `NSPanel` floating over full-screen Spaces with custom monochrome interlocking-S menu bar template icon, checkmark copy feedback, and `Tab` switching between Snippets and Clipboard modes.
- **Curated Snippets & Fuzzy Search (`FuzzySearchEngine`)**: SwiftData-backed snippet and colored tag storage with multi-token fuzzy matching, inline `#tag` filtering, pinned sorting, inline `⌘N` snippet creation, preview drawer, and dynamic variable expansion (`{{date}}`, `{{time}}`, `{{clipboard}}`).
- **50-Entry Clipboard History & Direct-Paste Bezel (`ClipboardHistoryStore`, `ClipboardBezelPanel`)**:
  - Background pasteboard monitor storing up to 50 deduplicated entries (configurable `10–50`) with `0600` local persistence.
  - Global `⌘⇧V` HUD bezel supporting **Hold `⌘` & Release `⌘` to Auto-Paste** via live CoreGraphics HID state checks without Input Monitoring permission.
  - Instant Search Mode (`⌘F` or `/`) across clipping text, source app name, and `#rank` (e.g. `#50`), plus one-key promotion (`S` / `⌘S`) into permanent Snippets.
- **Privacy & Secret Protection (`BiometricAuthService`, `ClipboardService`)**:
  - Masked secret snippets (`••••••••`) excluded from fuzzy body search and gated behind Touch ID / Apple Watch / macOS login password (`LAContext`).
  - Universal Clipboard / Handoff blocking (`.currentHostOnly`), `ConcealedType` / `TransientType` / `AutoGeneratedType` pasteboard markers, and `changeCount`-verified auto-clear (`5–300s`).
  - Owner-only `0700` storage directory at `~/Library/Application Support/SnipBar/`.
- **3-Column Library & Team Sharing (`LibrarySplitView`, `SnippetExchangeService`)**:
  - Full snippet, tag, secret, and clipboard management window (`⌘L` / `⌘,`) with Launch at Login (`SMAppService.mainApp`), configurable Snippets hotkey (`⌘⇧Space` or `⌥S`), and on-demand Accessibility Auto-Paste (`AutoPasteService`).
  - Selective or full `.snipbar.json` export and import with tag color preservation, exact-duplicate detection, and masked secrets unchecked by default.
- **Build, Test & CI Infrastructure**:
  - SwiftPM unit test suites (`FuzzySearchEngineTests`, `ClipboardHistoryStoreTests`, `SnippetExchangeServiceTests`).
  - XcodeGen project specification (`project.yml`) with ad-hoc "Sign to Run Locally" (`-`), `./scripts/build-release.sh`, GitHub Actions macOS-15 CI (`ci.yml`), and tag-triggered GitHub Release automation (`release.yml`).
