## Security & Privacy Model

SnipBar is designed to run 100% locally on macOS with zero network telemetry, zero cloud sync, and zero external package dependencies:

- **Local Storage Permissions**: SwiftData SQLite storage (`SnipBarStore.sqlite`) and clipboard history (`clipboard-history.json`) reside under `~/Library/Application Support/SnipBar/`, restricted to owner-only permissions (`chmod 0700` on the directory and `chmod 0600` on `clipboard-history.json`).
- **Masked Secrets**:
  - Secret snippets (`isSecret == true`) mask UI previews (`••••••••`), use `SecureField` in the editor, and exclude secret bodies from fuzzy search indexing.
  - Optional biometric confirmation uses `LAContext.evaluatePolicy(.deviceOwnerAuthentication)` (Touch ID, Apple Watch, or macOS login password).
  - Secret clipboard writes block Universal Clipboard / Handoff via `.currentHostOnly`, set `org.nspasteboard.ConcealedType`, `TransientType`, and `AutoGeneratedType`, and auto-clear after the configured timeout only if `NSPasteboard.general.changeCount` is unchanged.
- **Clipboard History Filtering**: `ClipboardHistoryStore` explicitly skips concealed, transient, auto-generated, and 1Password pasteboard items so third-party password managers and SnipBar secrets are never recorded in clipboard history.
- **Portable Exports (`.snipbar.json`)**: Masked secrets are unchecked by default in the export sheet. If explicitly selected by the user, exported JSON contains plaintext values and displays a warning before saving.

> **Important Threat-Model Note:** Because SnipBar uses ad-hoc "Sign to Run Locally" (`CODE_SIGN_IDENTITY = "-"`) without an Apple Developer provisioning profile, it does not use the Data Protection Keychain (`kSecUseDataProtectionKeychain`). File-level protection relies on macOS FileVault full-disk encryption and `0700`/`0600` POSIX permissions.

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report vulnerabilities privately using **GitHub Security Advisories** (under the repository's **Security → Advisories → Report a vulnerability** tab). Please include:

- A clear description of the vulnerability and potential impact
- Steps to reproduce (including macOS version and SnipBar version)
- Any suggested mitigations or patches, if available

We will acknowledge receipt promptly and work with you on a coordinated fix and disclosure timeline.
